# Milestone 3 Acceptance Checklist

- [ ] User can create a dataset.
- [ ] User can upload a flat CSV file.
- [ ] User can upload a JSON array.
- [ ] Dataset record count updates.
- [ ] Sample fields are detected.
- [ ] Natural-language input produces rules.
- [ ] Rules return matching records.
- [ ] Search is written to history.
- [ ] User cannot access another user's datasets.
- [ ] Dataset deletion cascades to records and history.

name,category,price,stock
Laptop Pro,electronics,950,8
